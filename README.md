# Loyalty Points Hub

A lightweight web app to manage loyalty points with:

- User signup/login (stored in localStorage)
- Credit card + points balance tracking
- Dashboard summary (cards, total points, top card)
- Built-in points assistant chat for redemption ideas

## Run locally

Open `index.html` directly in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
